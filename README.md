# Multi-Protocol Packet Router

A 4-port packet router designed in Verilog for routing data between multiple communication protocols.

## Project Status

**Work in Progress**

This project is currently under development. The RTL architecture, routing logic, arbitration, FIFOs, and protocol adapters are being implemented and verified progressively.

Planned protocol interfaces include:
- UART
- I2C

More modules, verification, documentation, and integration work will be added as the project progresses.

## Current Focus

- Packet routing architecture
- FIFO-based buffering
- Round-robin arbitration
- UART adapter
- I2C adapter
- Protocol-to-router integration
- RTL verification and simulation

> This README will be updated as the project reaches new development milestones.
